DHRUV PRASAD PORTFOLIO

Preview locally: open index.html in a browser, or use VS Code Live Server.

Before publishing:
1. Open index.html and replace YOUR_EMAIL@example.com with your real email address.
2. Check your LinkedIn profile URL and project details. Add real repository links when projects are ready.
3. Keep the image folder beside index.html and style.css.

Deploy free:
- Netlify: https://app.netlify.com/drop (drag the whole project folder or a ZIP after extracting).
- GitHub Pages: create a repository, upload all files/folders, then Settings > Pages > Deploy from a branch > main / root.

This is a static website; it does not require npm or a backend. The contact button opens the visitor's email app.
